# 📚 Exam Platform (HSC Level)

A full-stack **Exam Preparation Platform** built with **Next.js, Node.js, Express, and MongoDB** featuring custom authentication, role-based access, and secure JWT system.

---

## 🚀 Features

### 👤 Authentication
- Student Registration
- Student Login
- Admin Login (Fixed Credentials)
- JWT Access Token + Refresh Token
- Cookie-based authentication
- Role-based access control (Admin / Student)

---

### 🎓 Student Features
- Student Dashboard
- Secure login session
- Profile management (future scope)

---

### 🛠️ Admin Features
- Admin Dashboard
- Admin protected routes
- System control (future expansion)

---

### 🔐 Security
- Password hashing (bcryptjs)
- JWT authentication
- HTTP-only refresh token
- Middleware route protection
- Role-based access system

---

## 🏗️ Tech Stack

**Frontend:**
- Next.js
- React
- Custom CSS

**Backend:**
- Node.js
- Express.js
- MongoDB (Native Driver)
- JWT
- bcryptjs
- dotenv
- cookie-parser
